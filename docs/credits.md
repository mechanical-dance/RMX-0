# Credits and licence

RMX-0 stands on the work of others:

- **Erica Synths** wrote the LXR Eurorack module firmware and published it under the GPL-3.0 ([lxr-eurorack-app](https://github.com/erica-synths/lxr-eurorack-app)). RMX-0 is that firmware with additions; everything it does on the stock module comes from their code.
- **Julian Schmidt (Sonic Potions)** created the original LXR drum machine and its firmware, on which Erica Synths' LXR firmware is based. RMX-0's samples follow the original LXR's design.
- **Brendan Clarke** wrote [LXR02Open](https://github.com/brendanclarke/LXR02Open), which brought user samples and new LFO ideas to the LXR-02. It showed that samples could run from the module's flash and inspired the one-shot, exponential-triangle and smooth-random LFO shapes.
